# 10pshine

A note taking application built with React, Node.js, Express, and MongoDB.

## Features

- User authentication
- Rich Text Note creation and editing
- Note deletion
- Note search

## Installation

1. Clone the repository:

```bash
git clone https://github.com/RayanMern/10pshine.git
```

2. Navigate to the project directory:

```bash
docker compose up -d
```

3. Start Frontend:

```bash
cd frontend
pnpm dev
```

4. Start Backend:

```bash
cd backend
pnpm dev
```
